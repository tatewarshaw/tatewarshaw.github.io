# tatewarshaw.github.io

Files:
- index.html
- style.css
- script.js

To publish:
1. Create a new GitHub repository.
2. Upload these 3 files.
3. Go to Settings → Pages.
4. Under Build and deployment, choose "Deploy from a branch".
5. Choose main / root and Save.

The site is pure HTML/CSS/JS — no build step, npm, or framework required.
